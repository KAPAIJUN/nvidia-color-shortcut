====================================================
 NVIDIA 颜色设置工具（新版 NVIDIA App 适用）
====================================================

新版 NVIDIA 驱动不再自带老版「NVIDIA 控制面板」，颜色设置
（色调/灰度/数字振动）已整合进 NVIDIA App。本工具通过
NVAPI 直接调用驱动来设置颜色，不需要老版控制面板。

使用前提（Windows 10/11 64 位）：
  - NVIDIA 显卡 + 已安装最新驱动
  - 驱动自带 nvapi64.dll（安装驱动即有）


【一、打开颜色设置界面】
----------------------------------------------------
双击 open-nvidia-color.bat：
  - 如果装了老版 NVIDIA 控制面板：直接打开它；
  - 否则打开新版 NVIDIA App，按提示进入：
      设置 → 显示器 → 显示设置 → 颜色
    （英文界面：System → Displays → Display Settings → Color）


【二、一键来回切换（presets 文件夹）】
----------------------------------------------------
双击一次 = 开启，再双击 = 恢复默认，脚本会自动判断当前状态：

  toggle-vibrance-100.bat   数字振动 100（鲜艳）<-> 50（默认）
  toggle-vibrance-65.bat    数字振动 65 <-> 50（默认）
  toggle-hue-15.bat         色调 15° <-> 0°（默认）
  toggle-gamma-1.2.bat      灰度 1.2 <-> 1.0（默认）
  reset-all-color-defaults.bat  全部恢复默认

info-color.bat：查看当前数字振动 / 色调 / 灰度数值。


【三、工作原理 / 注意事项】
----------------------------------------------------
- 数字振动、色调：通过 NVAPI（nvapi64.dll）直接读写，和官方界面一致。
- 灰度：通过 Windows 灰度曲线（SetDeviceGammaRamp）实现，
  视觉上生效，但不会显示在 NVIDIA App 的灰度滑块里。
- 切换是「读取当前值 → 反着切」，不依赖状态文件；
  你在官方界面手动改过也能正确判断。
- 如果某个项目提示「不可用」，说明这台 GPU/驱动不支持该接口
  （例如部分 GPU 不支持 NVAPI 色调接口），其它项目不受影响。
- 想自定义数值：右键编辑 presets 里的 .bat，改 -On / -Off 后的数字。
  数字振动 0-100；色调 0-359；灰度建议 0.5-2.0。


【四、老版 NVIDIA 控制面板（可选）】
----------------------------------------------------
如果你还是想要老界面：微软商店里仍可安装「NVIDIA Control Panel」，
装完后 open-nvidia-color.bat 会优先打开它。

----------------------------------------------------
