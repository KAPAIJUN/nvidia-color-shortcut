====================================================
 NVIDIA 颜色设置快捷方式（用于 Windows）
====================================================

这套文件是给「另一台 Windows 电脑」用的，需要那台电脑：
  - 使用 NVIDIA 显卡，且已安装 NVIDIA 驱动
  - 系统 Windows 10 / 11

把整个文件夹拷到 Windows 电脑上（比如 D:\NVIDIA颜色设置\），
里面的文件不能删掉，因为脚本会读取同目录下的其它文件。


【一、一键打开「调整桌面颜色设置」页面】
----------------------------------------------------
第 1 步：双击 open-nvidia-color.bat（第一次运行）
  - 会自动打开 NVIDIA 控制面板；
  - 弹出提示框：请手动点开左侧「显示 → 调整桌面颜色设置」
    那一页，然后点「确定」，脚本会把这一页记住；
  - 弹窗询问是否在桌面创建快捷方式，选「是」，
    桌面就会出现「NVIDIA 颜色设置」快捷方式。

第 2 步：以后直接双击桌面上的「NVIDIA 颜色设置」，
  就会直接打开「调整桌面颜色设置」页（色调/灰度/数字振动那页）。

原理：NVIDIA 控制面板每次启动都会打开它“上次停留的页面”，
该记录保存在注册表：
  HKEY_CURRENT_USER\Software\NVIDIA Corporation\NVControlPanel2\Client\LastPage
脚本启动前把目标页面写回注册表，所以能一键直达。


【二、如果双击后没有直接到那一页】
----------------------------------------------------
- 说明你的驱动版本不使用这个记忆值。
  手动把控制面板停在那一页即可，以后它会记住。
- 也可以重新校准：删掉脚本同目录下的 nvcolor-lastpage.json，
  再运行一次 open-nvidia-color.bat。


【三、进阶：一键切换数字振动 / 灰度（来回切换）】
----------------------------------------------------
presets 文件夹里的 .bat 是「来回切换」模式：
双击一次 = 开启，再双击一次 = 恢复默认，如此循环。

  toggle-vibrance-100.bat     数字振动 100（鲜艳）<-> 50（默认）
  toggle-vibrance-65.bat      数字振动 65        <-> 50（默认）
  toggle-gamma-1.2.bat        灰度 1.2           <-> 1.0（默认）
  reset-all-color-defaults.bat  全部恢复默认，并清零切换记忆

说明：
  * 切换靠脚本自己记住状态（老接口 nvcpl.dll 无法读取当前值）。
    如果你在官方面板里手动改过值，切换记忆可能不准，
    先点一次 reset-all-color-defaults.bat 清零即可。
  * 多个数字振动预设改的是同一个设置，建议固定用一个来回切。
  * 新版驱动可能不带 nvcpl.dll，此时会弹窗提示暂不支持，
    直接用官方界面调即可；想要更可靠的切换，见下面第四节。
  * 预设里显示器编号写的是 0（主显示器），如果多显示器没生效，
    可编辑 presets\toggle-color.ps1 / reset-color-defaults.ps1，
    把 setgamma / setdefaults 里的 0 改成 1 或 2。


【四、更强大的方案（可选）】
----------------------------------------------------
如果以后想“一键切换游戏模式 / 桌面模式”，并支持色调(Hue)，
推荐开源工具 NVCP_Toggle（通过 NVAPI 直接改数字振动/色调/亮度/对比度/灰度）：
  https://github.com/mcgrizzz/NVCP_Toggle
需要 .NET Core 3.1 运行库（或下载它提供的 bundled 版）。


【五、说明】
----------------------------------------------------
- 本脚本在 macOS 上编写，无法在 Windows 上实机测试，
  请按上面步骤试一次；有问题把弹窗/报错内容发给我，我来改。
- 首次运行只需手动导航一次，之后全部一键直达。
